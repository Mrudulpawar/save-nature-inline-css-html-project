# save-nature-inline-css-html-project

This project is a simple webpage created using HTML and Inline CSS.

## Project Topic

The webpage is based on the theme:

- 💧 Save Water
- 🌳 Save Trees
- 🌍 Save Our Nature

## Technologies Used

- HTML
- Inline CSS

## CSS Used

Inline CSS is applied directly inside HTML elements using the `style` attribute.

Examples include:

- Color
- Background Color
- Text Alignment
- Padding
- Margin
- Border
- Font Size

## Purpose

The purpose of this project is to create awareness about saving water, protecting trees and keeping our nature clean and green.
